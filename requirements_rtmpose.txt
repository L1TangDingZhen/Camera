# ============================================================
# Section A: PC Installation (NVIDIA GPU with CUDA)
# ============================================================
#
# Prerequisites:
#   - NVIDIA GPU with CUDA support
#   - PyTorch with CUDA installed (torch.cuda.is_available() == True)
#   - CUDA 12.2+ recommended
#   - 8GB+ RAM recommended (mmcv compilation requires memory)
#
# Installation Steps:
#
# 1. Verify CUDA is available:
#    python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}, Version: {torch.version.cuda}')"
#
# 2. Install OpenMIM:
#    pip install openmim
#
# 3. Install mmengine (core dependency):
#    mim install mmengine==0.8.0
#
# 4. Install mmcv (computer vision library):
#    mim install mmcv==2.1.0
#
#    Note: mim automatically downloads the correct prebuilt wheel
#          for your PyTorch/CUDA version. Installation: 2-5 minutes
#
# 5. Install mmpose (pose estimation):
#    mim install mmpose==1.1.0
#
# 6. Verify installation:
#    python -c "import mmcv; print(f'mmcv: {mmcv.__version__}')"
#    python -c "import mmengine; print(f'mmengine: {mmengine.__version__}')"
#    python -c "import mmpose; print(f'mmpose: {mmpose.__version__}')"
#
# 7. Download RTMPose models:
#    python download_rtmpose_models.py --model rtmpose-s
#
# Windows-Specific Notes:
#   - If installation fails, consider using WSL2 (Windows Subsystem for Linux)
#   - Alternatively, continue using MediaPipe (set backend: mediapipe in config)
#   - CUDA toolkit must be installed on Windows for GPU support
#
# Common Issues:
#   - "No matching distribution": Your PyTorch/CUDA version may not have
#     prebuilt wheels. Try upgrading PyTorch or using different CUDA version
#   - Compilation errors: Ensure you have build tools installed
#     (Visual Studio Build Tools on Windows, gcc/g++ on Linux)

# ============================================================
# Section B: Jetson Installation (Orin/Xavier/Nano)
# ============================================================
#
# Prerequisites:
#   - JetPack 6.2.1+ (R36.4.0+) or JetPack 5.x (R35+)
#   - PyTorch 2.8.0+ installed from Jetson AI Lab PyPI
#   - CUDA 12.6+ support
#   - 4GB+ free RAM (8GB recommended, use swap if needed)
#
# Current Jetson Environment (2025-11-28):
#   - Device: Jetson Orin Nano Super (8GB)
#   - JetPack: 6.2.1 (R36.4.0)
#   - PyTorch: 2.8.0
#   - CUDA: 12.6
#   - Kernel: 5.15.148-tegra
#
# Installation Steps:
#
# 1. Verify CUDA is available:
#    python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}, Version: {torch.version.cuda}')"
#    # Should show: CUDA: True, Version: 12.6
#
# 2. Install OpenMIM:
#    pip install openmim
#
# 3. Install mmengine:
#    mim install mmengine==0.8.0
#
# 4. Install mmcv (WILL COMPILE FROM SOURCE):
#    mim install mmcv==2.1.0
#
#    ⚠️ IMPORTANT: This step compiles mmcv from source on Jetson
#       - Compilation time: 20-40 minutes (depends on Jetson model)
#       - High CPU usage is normal during compilation
#       - Do NOT interrupt the process
#       - Monitor with: watch -n 1 'ps aux | grep python'
#
#    If you see memory errors during compilation, enable swap:
#       sudo fallocate -l 4G /swapfile
#       sudo chmod 600 /swapfile
#       sudo mkswap /swapfile
#       sudo swapon /swapfile
#       # Verify: free -h
#
# 5. Install mmpose:
#    mim install mmpose==1.1.0
#
# 6. Verify installation:
#    python -c "import mmcv; print(f'mmcv: {mmcv.__version__}')"
#    python -c "import mmengine; print(f'mmengine: {mmengine.__version__}')"
#    python -c "import mmpose; print(f'mmpose: {mmpose.__version__}')"
#
#    Expected output:
#       mmcv: 2.1.0
#       mmengine: 0.8.0
#       mmpose: 1.1.0
#
# 7. Download RTMPose models:
#    python download_rtmpose_models.py --model rtmpose-s
#
# Jetson-Specific Notes:
#   - Use rtmpose-s or rtmpose-tiny for best real-time performance
#   - rtmpose-m/l may be too slow for real-time applications on Jetson
#   - TensorRT acceleration is optional but recommended for production
#
# Memory Requirements:
#   - Compilation: 4GB+ RAM (use swap if you have 4GB Jetson)
#   - Runtime: 2-3GB RAM for rtmpose-s
#
# Performance Expectations (Jetson Orin Nano):
#   - rtmpose-s: ~12-15ms inference, 20-25 FPS (720p)
#   - rtmpose-tiny: ~8-10ms inference, 25-30 FPS (720p)
#   - rtmpose-m: ~25-30ms inference, 15-20 FPS (720p, not recommended)

# ============================================================
# Alternative: Continue Using MediaPipe
# ============================================================
#
# If RTMPose installation fails or takes too long, you can
# continue using MediaPipe (default pose estimator):
#
# Advantages of MediaPipe:
#   - Zero compilation, instant installation
#   - CPU-friendly, works on any platform
#   - Good accuracy for most use cases (AP ~67%)
#   - Already installed in requirements_jetson.txt
#
# To use MediaPipe, set this in your config:
#   models:
#     pose:
#       backend: mediapipe  # Default, no RTMPose needed
#       complexity: 1
#       device: cpu
#
# MediaPipe vs RTMPose Performance Comparison:
#
#   Platform: PC (RTX 4070)
#   - MediaPipe (CPU): ~50ms, AP 67%
#   - RTMPose-s (GPU): ~12ms, AP 68.6%
#
#   Platform: Jetson Orin Nano
#   - MediaPipe (CPU): ~80-100ms, AP 67%
#   - RTMPose-s (GPU): ~12-15ms, AP 68.6%
#
# For most use cases, MediaPipe is sufficient. Switch to RTMPose
# only if you need GPU acceleration or better performance.

# ============================================================
# Troubleshooting
# ============================================================
#
# Problem: "CUDA out of memory" during installation
# Solution:
#   - Enable swap (see Section B step 4)
#   - Close other applications
#   - Use lighter model (rtmpose-tiny instead of rtmpose-s)
#
# Problem: "No module named 'mmcv'"
# Solution:
#   - Do NOT use "pip install mmcv", always use "mim install mmcv==2.1.0"
#   - Verify mim is installed: pip show openmim
#
# Problem: Compilation hangs or takes forever
# Solution:
#   - This is normal for Jetson, wait 20-40 minutes
#   - Monitor progress: watch -n 1 'ps aux | grep python'
#   - Do not interrupt, it will corrupt installation
#
# Problem: "ImportError: cannot import name 'Config' from 'mmcv'"
# Solution:
#   - Version mismatch, uninstall and reinstall:
#     pip uninstall mmcv mmengine mmpose -y
#     mim install mmengine==0.8.0
#     mim install mmcv==2.1.0
#     mim install mmpose==1.1.0
