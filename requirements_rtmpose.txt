# RTMPose Dependencies Installation Guide
# ============================================================
# This file provides installation instructions for RTMPose pose estimator.
# RTMPose requires mmcv and mmpose packages from OpenMMLab.
#
# Choose the appropriate installation method based on your platform:
#   - PC Users (Linux/Windows): See Section A
#   - Jetson Users (Orin/Xavier): See Section B
#
# For detailed troubleshooting, refer to: INSTALL_RTMPOSE.md
# ============================================================

# Required for both platforms
openmim>=0.3.9

# ============================================================
# Section A: PC Installation (NVIDIA GPU with CUDA)
# ============================================================
#
# Prerequisites:
#   - NVIDIA GPU with CUDA support
#   - PyTorch with CUDA installed (torch.cuda.is_available() == True)
#   - 8GB+ RAM recommended (mmcv compilation requires memory)
#
# Installation Steps:
#
# 1. Install OpenMIM (already included above)
#    pip install openmim
#
# 2. Install mmengine (required dependency for mmcv)
#    mim install mmengine==0.8.0
#
# 3. Install mmcv (OpenMMLab computer vision library)
#    mim install mmcv==2.0.0
#
#    Note: mim will automatically download the correct prebuilt wheel
#          for your PyTorch/CUDA version. No manual compilation needed.
#          Installation time: 2-5 minutes
#
# 4. Install mmpose (pose estimation library)
#    mim install mmpose==1.0.0
#
# 5. Verify installation
#    python -c "import mmcv; print(f'mmcv: {mmcv.__version__}')"
#    python -c "import mmengine; print(f'mmengine: {mmengine.__version__}')"
#    python -c "import mmpose; print(f'mmpose: {mmpose.__version__}')"
#
# 6. Download RTMPose models
#    python download_rtmpose_models.py --model rtmpose-s
#
# Windows Users:
#   - If mmcv installation fails on Windows, consider:
#     1. Use WSL2 (Windows Subsystem for Linux)
#     2. Continue using MediaPipe (backend: mediapipe)
#     3. Deploy directly to Jetson for production
#
# Common Issues:
#   - "No matching distribution found": Your PyTorch/CUDA version may not
#     have prebuilt wheels. Try upgrading PyTorch or use a different CUDA version.
#   - Compilation errors: Make sure you have Visual Studio Build Tools (Windows)
#     or gcc/g++ (Linux) installed.

# ============================================================
# Section B: Jetson Installation (Orin/Xavier/Nano)
# ============================================================
#
# Prerequisites:
#   - JetPack 6.x (R36+) or JetPack 5.x (R35+)
#   - PyTorch with CUDA installed from Jetson AI Lab PyPI
#   - 4GB+ free RAM (swap recommended for 4GB models)
#
# Installation Steps:
#
# 1. Install OpenMIM (already included above)
#    pip install openmim
#
# 2. Install mmengine (required dependency)
#    mim install mmengine==0.8.0
#
# 3. Install mmcv (will compile from source)
#    mim install mmcv==2.0.0
#
#    ⚠️ IMPORTANT: This step compiles mmcv from source on Jetson
#       - Compilation time: 20-40 minutes (depends on model)
#       - High CPU usage is normal
#       - Do NOT interrupt the process
#       - If compilation fails with memory error, enable swap:
#         sudo fallocate -l 4G /swapfile
#         sudo chmod 600 /swapfile
#         sudo mkswap /swapfile
#         sudo swapon /swapfile
#
# 4. Install mmpose
#    mim install mmpose==1.0.0
#
# 5. Verify installation
#    python -c "import mmcv; print(f'mmcv: {mmcv.__version__}')"
#    python -c "import mmengine; print(f'mmengine: {mmengine.__version__}')"
#    python -c "import mmpose; print(f'mmpose: {mmpose.__version__}')"
#
# 6. Download RTMPose models
#    python download_rtmpose_models.py --model rtmpose-s
#
# Jetson-Specific Notes:
#   - Use rtmpose-s or rtmpose-tiny for best performance
#   - rtmpose-m/l may be too slow for real-time applications
#   - TensorRT acceleration is optional but recommended for production
#
# Memory Requirements:
#   - Compilation: 4GB+ RAM (use swap if needed)
#   - Runtime: 2GB+ RAM for rtmpose-s
#
# Tested Configurations:
#   - Jetson Orin Nano: JetPack 6.2.1 + PyTorch 2.8.0 + CUDA 12.6 ✓
#   - Jetson Orin NX:   JetPack 6.1   + PyTorch 2.5.0 + CUDA 12.2 ✓
#   - Jetson Xavier NX: JetPack 5.1   + PyTorch 2.0.0 + CUDA 11.4 ✓

# ============================================================
# Section C: Alternative - Use MediaPipe Instead
# ============================================================
#
# If mmcv/mmpose installation fails or takes too long, you can
# continue using MediaPipe (default pose estimator):
#
# Advantages of MediaPipe:
#   - Zero compilation, instant installation
#   - CPU-friendly, works on any platform
#   - Good accuracy for most use cases (AP ~67%)
#   - Already installed in your environment
#
# To use MediaPipe, simply keep this config:
#   models:
#     pose:
#       backend: mediapipe  # Default, no changes needed
#       complexity: 1
#       device: cpu
#
# MediaPipe vs RTMPose comparison:
#   - MediaPipe: ~50ms (CPU), AP 67%, easy installation
#   - RTMPose-s: ~12ms (GPU), AP 68.6%, complex installation
#
# For most users, MediaPipe is sufficient. Switch to RTMPose
# only if you need GPU acceleration or slightly better accuracy.
